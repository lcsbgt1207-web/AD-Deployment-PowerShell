# Contribuer à ce projet

Ce projet est ouvert aux contributions dans le cadre d'un apprentissage en cybersécurité.

## Ce que tu peux faire

- Signaler un bug ou une amélioration via les **Issues**
- Proposer une modification via une **Pull Request**
- Améliorer la documentation ou le README

## Comment contribuer

1. Fork le repo
2. Crée une branche : `git checkout -b ma-modification`
3. Fais tes modifications
4. Commit : `git commit -m "Description de la modification"`
5. Push : `git push origin ma-modification`
6. Ouvre une Pull Request

## Bonnes pratiques

- Commente ton code PowerShell
- Teste sur une VM avant de proposer
- Décris clairement ce que fait ta modification
